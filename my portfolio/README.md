# RM — Backend Developer Portfolio

A modern, animated portfolio website showcasing a Computer Science student's backend development projects and skills.

## ✨ Features

- **Hero Section**: Large animated hero with avatar, social links, and call-to-action buttons
- **Dark Neon Theme**: Purple and cyan gradient with glassmorphic design elements
- **Animated Avatar**: Cool lion character with sunglasses and hoodie
- **Responsive Design**: Mobile-first approach, fully responsive on all screen sizes
- **Smooth Animations**: Reveal animations on scroll, floating orbs, interactive buttons
- **Project Showcase**: Featured projects with tech stack tags and descriptions
- **Skills Grid**: Display of tools and technologies
- **Contact Form**: Direct messaging capability
- **Sticky Navigation**: Easy navigation with active link indicators

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Modern styling with gradients, filters, and animations
- **JavaScript (Vanilla)** — Interactive menu toggle and scroll reveal animations
- **SVG** — Custom avatar graphics

## 📁 Project Structure

```
my portfolio/
├── index.html          # Main HTML file
├── styles.css          # All styling and animations
├── script.js           # JavaScript interactivity
├── assets/
│   └── lion.svg        # Custom avatar
└── README.md           # This file
```

## 🚀 Quick Start

1. Open `index.html` in your browser
2. No build step or dependencies required
3. Fully self-contained and works offline

## 📱 Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge)

## 🎨 Color Palette

- Primary Purple: `#7c3aed`
- Accent Cyan: `#22d3ee`
- Dark Background: `#0a0612`
- Light Text: `#e6eef8`

## 🔧 Customization

- **Colors**: Edit CSS variables in `styles.css` `:root` section
- **Content**: Update text and links in `index.html`
- **Avatar**: Replace `assets/lion.svg` with your own
- **Projects**: Modify project cards in the projects section
